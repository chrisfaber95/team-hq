# Babylon walkthrough notes (for F-012)

Looked up 2026-10-17. GameFAQs link from the user (N64 FAQ 43548) returned HTTP 403; note it is the
N64 port, which can differ from the PC game. Used instead:

- https://www.cyberly.org/game-cheats/pc-walkthroughs/indiana-jones-and-the-infernal-machine.html (Babylon = level 2; lists 10 treasures; text read up to char 100000 of 123397)
- https://coregamers.com/walkthrough/indiana-jones-and-the-infernal-machinetm (21 ordered areas; treasures only loosely located; no secrets listed; read up to char 100000 of 139033)

Area order (both agree): ruins exterior and rooftops, spider cave, barrel cave and guards, tent camp
with lever/crank gate, truck jump into the compound, base battle, base lever, water tunnels (pull crate
to reveal), key from the CIA agent / Simon Turner, TNT room, mechanism room, library and tablet pieces,
elevator exit. Level ends at the jeep.

Disagreements: treasure order and count; who gives the key (named differently); the sources use
different names for the camp contact.
